**EzBookNow** စနစ်၏ အသုံးပြုသူများ (End Users) အတွက် **Pkg1 Core** ဗားရှင်းတွင် ပါဝင်သော **User Screen စာရင်း (U-01 မှ U-14 အထိ စုစုပေါင်း ၁၄ ခု)** 1-3 နှင့် ၎င်းတို့ အချင်းချင်း ချိတ်ဆက်ကူးပြောင်းပုံ **Screen Transition Flow** အသေးစိတ်မှာ အောက်ပါအတိုင်း ဖြစ်ပါသည် \-

### ၁။ User Screen စာရင်း (User Screen List)

* **U-01: 予約ページ (Booking Page / SNS မှ 着地点)**  
* **URL:** /s/{slug} 2, 4, 5  
* ဆိုင်၏ SNS သို့မဟုတ် 店頭QR Direct Link မှတစ်ဆင့် ဖောက်သည်များ တိုက်ရိုက်ရောက်ရှိမည့် ပထမဆုံး စတင်ရာ မျက်နှာပြင် ဖြစ်ပါသည်။ ရောက်ရှိသည်နှင့် ရက်စွဲ၊ လူဦးရေနှင့် အားလပ်သည့် အချိန်ကွက် (Slot) များကို ချက်ချင်း ရွေးချယ်နိုင်ပါသည် 4, 5။  
* **U-02: 予約入力 (Booking Input)**  
* ဧည့်သည်၏ အမည်၊ ဖုန်းနံပါတ်၊ အီးမေးလ် (မဖြစ်မနေ မဟုတ်ပါ)၊ လိုချင်သော ဝိုင်းအမျိုးအစား (Preferred seat tags) နှင့် ငွေပေးချေမှုပုံစံများကို ဖြည့်သွင်းသည့် မျက်နှာပြင် ဖြစ်ပါသည်။ (အကောင့်မရှိသူ Guest များလည်း အသုံးပြုနိုင်ပါသည်) 2, 5။  
* **U-03: 予約確認 (Booking Confirmation)**  
* မှာယူမည့် အချက်အလက်များ၊ ဆိုင်၏ စည်းကမ်းချက်များကို စစ်ဆေး အတည်ပြုသည့် မျက်နှာပြင် ဖြစ်ပါသည် 2, 5။ (ဖုန်းနံပါတ် မစစ်ဆေးရသေးပါက U-13 SMS OTP သို့ ခဏသွားရောက် အတည်ပြုရပါမည်) 5, 6။  
* **U-04: 予約完了 (Booking Completed)**  
* ကြိုတင်မှာယူမှု အောင်မြင်သွားပြီးနောက် **予約番号 (Booking No.)** နှင့် ဆိုင်သို့ ပြသရန် **QR Code** ထွက်ပေါ်လာသည့် မျက်နှာပြင် ဖြစ်ပါသည် 2, 5။  
* **U-05: 店舗情報ページ (Shop Info Page)**  
* **URL:** /s/{slug}/info 2, 4, 5  
* U-01 ပေါ်ရှိ **"お店の情報を見る"** ခလုတ်မှတစ်ဆင့် ခွဲထွက်ကြည့်ရှုနိုင်ပြီး ဆိုင်၏ ဓာတ်ပုံများ၊ မီနူးစာရင်း၊ ဆိုင်ဖွင့်ချိန်နှင့် တည်နေရာပြ မြေပုံများ ပါဝင်ပါသည်။ အထက်နှင့် အောက်တွင် "予約する" ခလုတ်ဖြင့် U-01 သို့ ပြန်သွားနိုင်ပါသည် 4-6။  
* **U-06: ログイン / 予約照会 (Login / Booking Lookup)**  
* **Tab ၁ (ログイン):** Facebook/Google SSO၊ အီးမေးလ် သို့မဟုတ် ဖုန်းနံပါတ် \+ SMS OTP ဖြင့် အကောင့်ဝင်ရောက်ရန် 5, 7။  
* **Tab ၂ (予約番号で照会):** အကောင့်မရှိဘဲ Guest အဖြစ် မှာယူထားသူများ မိမိမှာယူမှုကို **予約番号 \+ ဖုန်းနံပါတ်** ဖြင့် ပြန်လည်စစ်ဆေး/ပယ်ဖျက်ရန် Entrada ဖြစ်ပါသည် 2, 5။  
* **U-07: 会員登録 (Register)**  
* အကောင့်သစ် ပြုလုပ်ခြင်း (SSO / အီးမေးလ် / ဖုန်းနံပါတ် \+ SMS OTP) နှင့် စနစ်၏ စည်းကမ်းချက်များ သဘောတူညီချက် ရယူသည့် မျက်နှာပြင် ဖြစ်ပါသည် 5, 7။  
* **U-08: パスワードリセット (Password Reset)**  
* စကားဝှက် မေ့သွားသူများအတွက် ပြန်လည်သတ်မှတ်နိုင်မည့် လင့်ခ်ကို အီးမေးလ်သို့ ပေးပို့ပေးသည့် မျက်နှာပြင် ဖြစ်ပါသည် 2, 5။  
* **U-09: マイページ \- 予約履歴 (My Page / Booking History)**  
* အကောင့်ဝင်ထားသော အဖွဲ့ဝင်များ၏ နောင်လာမည့် မှာယူမှုများနှင့် ယခင်မှာယူခဲ့ဖူးသော သမိုင်းကြောင်းများကို စုစည်းပြသပေးသည့် မျက်နှာပြင် ဖြစ်ပါသည် 2, 5။  
* **U-10: 予約詳細・変更・キャンセル (Booking Detail / Change / Cancel)**  
* မှာယူမှု အသေးစိတ် ကြည့်ရှုခြင်း၊ ရက်စွဲ/လူဦးရေ အခမဲ့ ပြောင်းလဲခြင်း သို့မဟုတ် လာရောက်မည့် အချိန်အထိ **အခမဲ့ အကန့်အသတ်မရှိ ပယ်ဖျက်ခြင်း** ပြုလုပ်နိုင်သည့် မျက်နှာပြင် ဖြစ်ပါသည် 5, 7။  
* **U-11: アカウント設定・退会 (Account Settings / Delete)**  
* ကိုယ်ရေးအချက်အလက် (အီးမေးလ်/ဖုန်း/စကားဝှက်) ပြောင်းလဲခြင်း၊ စနစ်ပြသရေး ဘာသာစကား (EN/MM/JA) ရွေးချယ်ခြင်းနှင့် အကောင့် ဖျက်သိမ်းခြင်း (PDPA) ပြုလုပ်ရန် ဖြစ်ပါသည် 5, 7, 8။  
* **U-12: サービス紹介 \- ルートLP (Service LP / Root LP)**  
* Root URL (/) သို့ တိုက်ရိုက်ရောက်ရှိလာသူများအတွက် စနစ်အကြောင်း ရှင်းပြထားသည့် Static LP မျက်နှာပြင် ဖြစ်ပါသည် 2, 5, 9။  
* **U-13: SMS認証 \- OTP入力 (SMS Verification / OTP Input)**  
* ဖုန်းနံပါတ် မှန်ကန်ကြောင်း ဂဏန်း ၆ လုံးပါ SMS OTP ရိုက်ထည့်၍ အတည်ပြုပေးရသည့် မျက်နှာပြင် ဖြစ်ပါသည် 5, 7။  
* **U-14: 通知センター (Notification Center)**  
* အဖွဲ့ဝင်များအတွက် အက်ပ်တွင်း အသိပေးချက်များ (In-App Notifications) ကြည့်ရှုရာ စင်တာ ဖြစ်ပါသည် 5, 7, 10။

### ၂။ Screen Transition စီးဆင်းပုံ (Screen Transition Flow)

#### ❶ အဓိက ကြိုတင်မှာယူမှု စီးဆင်းပုံ (Core Booking Flow)

* **着地点 (Landing Point):** ဖောက်သည်သည် ဆိုင်၏ Facebook/Instagram သို့မဟုတ် 店頭QR လင့်ခ် (/s/{slug}) မှတစ်ဆင့် **U-01 (予約ページ)** သို့ **တိုက်ရိုက် ရောက်ရှိပါမည်** 4, 6, 11။  
* **သတင်းအချက်အလက် ကြည့်ရှုခြင်း (Optional):** U-01 ပေါ်ရှိ **"お店の情報を見る"** ခလုတ်ကို နှိပ်ပါက **U-05 (店舗情報ページ)** သို့ ခွဲထွက်ကြည့်ရှုနိုင်ပြီး၊ **"予約する"** ကို ပြန်နှိပ်ပါက ရွေးချယ်ထားသော အခြေအနေအတိုင်း **U-01** သို့ ပြန်လည်ရောက်ရှိပါမည် 4, 6, 11။  
* **မှာယူမှု အဆင့်ဆင့်:**\\\\\\mathbf{U-01 \\text{ (ရက်စွဲ/အချိန်ကွက် ရွေး)}} \\longrightarrow \\mathbf{U-02 \\text{ (အချက်အလက် ဖြည့်)}} \\longrightarrow \\mathbf{U-03 \\text{ (အတည်ပြု)}} \\longrightarrow \\mathbf{U-04 \\text{ (မှာယူမှု ပြီးမြောက်)}}\\\\ 4, 6, 11  
* **OTP စစ်ဆေးခြင်း:** U-03 တွင် ဖုန်းနံပါတ် မစစ်ဆေးရသေးပါက **U-13 (SMS OTP)** သို့ ခဏသွားရောက် အတည်ပြုပြီးနောက် **U-03** သို့ ပြန်လည်ရောက်ရှိကာ မှာယူမှု ပြီးမြောက်သွားပါမည် 5, 6။

#### ❷ အကောင့်ဝင်ခြင်းနှင့် အကောင့်သစ်ဖွင့်ခြင်း (Auth Flow)

* U-01 သို့မဟုတ် U-02 တွင် အကောင့်ဝင်ရန် **U-06 (ログイン)** သို့မဟုတ် အကောင့်သစ်ဖွင့်ရန် **U-07 (会員登録)** သို့ သွားရောက်နိုင်ပါသည် 6။  
* **ဖုန်းနံပါတ်+SMS OTP** နည်းလမ်းကို ရွေးချယ်ပါက **U-13 (SMS OTP)** မျက်နှာပြင်တွင် စစ်ဆေးပြီးသည်နှင့် မူလ ရောက်ရှိနေသော **U-02 予約入力** မျက်နှာပြင်သို့ အလိုအလျောက် ပြန်လည်ပို့ဆောင်ပေးပါမည် 5, 6။

#### ❸ မှာယူမှု ပြန်လည်စစ်ဆေး/ပြောင်းလဲ/ပယ်ဖျက်ခြင်း (Lookup & Change Flow)

* **အကောင့်ရှိသူများ (Members):** **U-09 (マイページ)** ➔ **U-10 (予約詳細)** သို့ သွားရောက်၍ ရက်စွဲပြောင်းလဲခြင်း သို့မဟုတ် အခမဲ့ ပယ်ဖျက်ခြင်း ပြုလုပ်နိုင်ပါသည်။  
* **အကောင့်မရှိသူများ (Guest Users):** **U-06 ( Tab 2: 予約番号で照会)** တွင် မိမိ၏ **予約番号 \+ ဖုန်းနံပါတ်** ရိုက်ထည့်၍ **U-10 (予約詳細)** သို့ တိုက်ရိုက်ဝင်ရောက် ကြည့်ရှု/ပယ်ဖျက်နိုင်ပါသည် 2, 5, 6။

💬 **Shop Screens (S-xx)** သို့မဟုတ် **Admin Screens (AD-xx)** များ၏ Screen Transition Flow ကိုရော ဆက်လက်ကြည့်ရှုလိုပါသလားခင်ဗျာ။
