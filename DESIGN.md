# User Portal Design System (Isolated)

This document contains the independent UI/UX Design System specifications for the EzBookNow **User Portal (Customer UI)**.

## Brand & Style
The design system for the User portal targets guest and customer reservation flows with an emphasis on clarity, visual speed, and seamless booking actions.

## Colors
- **Primary Navy Blue (`#131546`)**: Header navigation, primary accents.
- **Vibrant Lime (`#AAF457`)**: Call-to-action (CTA) buttons, booking confirmation indicators.
- **Soft Background (`#F8F9FA`)**: Off-white backdrop reducing eye strain.

## Typography
- **Headline**: Outfit / Padauk / Noto Sans Myanmar
- **Body & Controls**: Inter / Padauk / Noto Sans Myanmar
