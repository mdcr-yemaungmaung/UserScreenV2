# Implementation Plan: Component Gallery / Design System Screen

**Branch**: `001-component-gallery` | **Date**: 2026-08-23 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-component-gallery/spec.md`

## Summary

Add a single "Design System" screen that renders every reusable UI component
(colors, typography, buttons, cards, tags, forms, feedback, navigation) for
visual review. It is reachable from the MyPage menu and renders inside the
existing MyPage shell — no new routing, no framework.

## Technical Context

**Language/Version**: Vanilla JavaScript (ES5-style IIFEs attaching to
`window.YoyakuComponents`), Tailwind CSS v4 (compiled via CLI).

**Primary Dependencies**: Existing component render functions already exposed on
`window.YoyakuComponents` (RestaurantCard badges/tags/cards, TopNavBar,
BottomNavBar, Toast, InfoModals, CalendarPicker). No new runtime dependency.

**Storage**: N/A — prototype reads mock data from `YoyakuData.RESTAURANTS_DATA`.

**Testing**: Manual visual verification at 320px / 375px / 1024px (no automated
test framework in this prototype).

**Target Platform**: Mobile web (320–1024px), PWA on Vercel.

**Project Type**: Static web app / UI prototype.

**Performance Goals**: No layout shift; instant open from MyPage menu.

**Constraints**: All new class names MUST be compiled via `npm run build:css`
(constitution Principle II). No horizontal scroll at 320px (Principle I). No
`node_modules` commit (Principle VI).

**Scale/Scope**: 1 new screen file + 2 edits in `u08-mypage.js` + 1 index.html
script tag.

**Structure Decision**: Follows the existing "one IIFE per screen attaching to
`window.YoyakuComponents`" convention. The gallery reuses already-exported
component renderers rather than duplicating markup, so it stays in sync with the
real components it displays.

## Implementation Approach

1. **u22-components.js**: IIFE that builds sections from helper sub-render
   functions (color swatches from a token array, typography samples, buttons
   incl. favorite-bounce button, live cards from `YoyakuData.RESTAURANTS_DATA`,
   tags/badges, form inputs, feedback triggers, nav previews). Exposes
   `window.YoyakuComponents.renderComponentGallery`.
2. **u08-mypage.js**: push `{ id:'design-system', label, icon:'palette' }` into
   `menuItems`; add `if (activeMenu === 'design-system') return
   window.YoyakuComponents.renderComponentGallery(state)` in
   `renderActiveScreenPanel()`.
3. **index.html**: add the script tag before `js/main.js`.
4. **CSS**: run `npm run build:css`.
